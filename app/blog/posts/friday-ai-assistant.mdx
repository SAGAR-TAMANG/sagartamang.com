## 🌱 Where It Started: The Open-Source F.R.I.D.A.Y.

Friday began as an open-source project — a **Tony Stark F.R.I.D.A.Y. clone** I put on GitHub to see if I could make a genuinely low-latency voice agent. It resonated way more than I expected, crossing **1k+ stars**.

- ⭐ **Open-source repo:** [github.com/SAGAR-TAMANG/friday-tony-stark-demo](https://github.com/SAGAR-TAMANG/friday-tony-stark-demo)
- 🧩 **Project write-up:** [F.R.I.D.A.Y. — the build breakdown](/projects/friday-jarvis-clone)

The open-source version was built for **flexibility**. Rather than locking you into one provider, it let you mix and match the best model for each stage of the voice pipeline:

- **Speech-to-text (STT):** Sarvam Saaras v3, Deepgram, or OpenAI
- **LLM / reasoning:** Google Gemini 2.5 Flash for fast time-to-first-token
- **Text-to-speech (TTS):** OpenAI Nova, ElevenLabs, and others

Architecturally, it split into two cooperating layers: a **LiveKit**-powered real-time voice pipeline that listens and speaks, and a **FastMCP** "brain" server that did the actual tool execution (news, web search, system info) over Server-Sent Events. Decoupling the voice loop from the tools meant you could add new capabilities without ever breaking the conversation.

That design is still the best starting point if you want to **build your own AI voice assistant** — the code is all there, MIT-licensed.

## 🚀 The Upgrade: A Real Desktop App

The open-source version proved the idea. But "clone a GitHub repo, set five API keys, and run a Python server" is not something most people will do. To make Friday something anyone could actually *use*, it needed to be a real, installable **desktop AI assistant**.

So I rebuilt it as a native desktop app — and made one big architectural decision: **the shipped version runs entirely on OpenAI.**

Instead of stitching together Sarvam + Gemini + ElevenLabs, the released Friday uses **OpenAI's Realtime API** (`@openai/agents/realtime`) end to end. One provider, one key, dramatically simpler setup, and a tighter, lower-latency voice loop. The multi-provider flexibility still lives on in the open-source edition for tinkerers — but the product you download is the streamlined, OpenAI-native version.

> The released app is the **upgraded** version of the open-source project: better UI, tighter latency, and a genuinely polished experience. Same soul, production-grade build.

## 🔒 The Best Part: It's Yours, and It's Private

Here's what makes Friday different from most **AI assistant apps**: it's **bring-your-own-key (BYOK)** and **privacy-first by design**.

When you use Friday, your voice, your screen captures, your searches, and your computer-control actions go **straight from your device to OpenAI, using your own API key.** Nothing routes through my servers. I don't see your conversations, I don't store your screen, and I don't proxy your data.

You get a J.A.R.V.I.S.-style assistant that answers only to you — not a subscription that funnels your private desktop through someone else's cloud.

## 🛠️ How Friday Is Built (For the Developers)

If you care about the stack, here's the shipped architecture:

- **Shell:** Electron desktop app — a transparent, always-on-top "Dynamic Island"–style overlay that expands when you talk to it.
- **Voice:** OpenAI Realtime (`@openai/agents/realtime`) hosted inside the app for the full speech-to-speech loop.
- **Vision:** a screen-capture tool that lets the agent *look at your screen* and reason about it.
- **Web search:** OpenAI's hosted web search tool for live information.
- **Computer control:** desktop input automation so the agent can move the mouse, type, and drive apps.
- **Security:** the real OpenAI key is encrypted at rest on-device; the app mints short-lived ephemeral keys so the actual secret never leaves your machine.

It's a genuinely good reference for anyone building an **AI agent that controls your computer**, an **OpenAI Realtime voice app**, or an **Electron AI assistant**.
